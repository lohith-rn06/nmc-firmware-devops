# ADR 0004: SNMPv3 (USM authPriv) is on the roadmap

**Status:** Accepted

## Decision
v1/v2c are kept read-only for compatibility with legacy NMS. v3 with SHA-256/AES-128 is required for the IEC 62443 SL2 target and is planned for 1.5.
